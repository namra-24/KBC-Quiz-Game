# 🎯 Kaun Banega Crorepati (KBC) Quiz Game

## Overview

This is a Python-based quiz game inspired by the famous Indian television show **Kaun Banega Crorepati (KBC)**. Players answer multiple-choice questions to win increasing amounts of virtual prize money. The game includes background music and sound effects to provide an engaging experience.

---

## Features

✅ User-friendly graphical interface using Tkinter

✅ Multiple-choice quiz questions

✅ Progressive prize money ladder

✅ Background music throughout gameplay

✅ Correct and incorrect answer sound effects

✅ Instant result notifications

✅ Win and Game Over screens

## How to Play

1. Launch the game.
2. Read the question displayed on the screen.
3. Select one of the four answer options.
4. Click the **Submit** button.
5. If the answer is correct:

   * You advance to the next question.
   * You earn the corresponding prize money.
6. If the answer is incorrect:

   * The game ends immediately.
7. Answer all questions correctly to win the game.
